One extra step

This game needs a local server

Browsers block JavaScript modules when a page is opened straight from disk, so the canvas stays blank.

Double-click start_server.bat

It serves this folder at http://localhost:8080/ and opens your browser.

Or run python -m http.server 8080 in this folder and visit localhost:8080.

Mobile app mode

Turn your phone sideways

Down, Down, Down is a landscape game. Rotate the device and it fills the screen edge to edge.
